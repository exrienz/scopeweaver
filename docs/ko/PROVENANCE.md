# ScopeWeaver 출처와 변경 사항

[English](../PROVENANCE.md) · 한국어 · [简体中文](../zh-Hans/PROVENANCE.md) · [繁體中文](../zh-Hant/PROVENANCE.md) · [日本語](../ja/PROVENANCE.md) · [Español](../es/PROVENANCE.md)

ScopeWeaver는 [Autumn-27/ARTEX](https://github.com/Autumn-27/ARTEX)의 커밋 `160fe13`을 바탕으로 만든 독립 파생 프로젝트입니다. GitHub 포크 네트워크 관계 없이 [cskwork/scopeweaver](https://github.com/cskwork/scopeweaver)에서 별도로 관리합니다.

**2026-10-02** ScopeWeaver 변경 범위는 제품 이름, 영어 기본/한국어 선택 화면과 메시지, 문서와 내장 에이전트 지침, 설치/빌드/시작/업데이트/비밀번호 재설정 안내, 보고서 및 에이전트 언어 처리, 배포 이름입니다. 실행 파일은 `scopeweaver`(Windows는 `scopeweaver.exe`)이며 압축 파일 이름은 `scopeweaver-<version>-<os>-<arch>.zip`입니다. Docker Compose는 현재 소스를 로컬에서 빌드합니다. 릴리스 워크플로는 이 저장소와 GHCR을 대상으로 설정되어 있습니다.

원본 `LICENSE`는 변경 없이 유지합니다. 원저자, 기여자 감사, 원본 변경 기록은 ARTEX의 기록으로 명시합니다. 호환성을 위해 Go 모듈 `github.com/Autumn-27/artex`, 진입 소스 `./cmd/artex`, `ARTEX_*` 설정, `artex` 데이터베이스 기본값, `ARTEX` 로그인 이름을 유지합니다.

이 변경 날짜는 릴리스 태그가 아니며 바이너리 릴리스나 컨테이너 이미지 공개를 뜻하지 않습니다. `sidequestion/`의 과거 검증 문서는 원본 실행 기록이며 새 ScopeWeaver 검증 결과가 아닙니다. 번역된 과거 JSON은 기술 식별자와 측정값을 유지하고 서술 번역임을 표시합니다.

**2026-10-15** 변경에서는 선택형 기본 Ollama 프로필 형식(`num_ctx`, `keep_alive`, `num_predict`를 보내는 `/api/chat`), 새 프로필 전용 Ollama 템플릿 세 개, 키 없는 로컬 프로필, 프로필별 동시 요청 수, Ollama에 맞춘 예열·압축·승인 판정 기본값, 선택형 `local_llm_only` LLM 네트워크 정책을 추가합니다. `SCOPEWEAVER_LLM_*`와 `SCOPEWEAVER_LOCAL_LLM_*` 변수는 유지하는 `ARTEX_*` 설정보다 우선하는 별칭입니다. 기존 Anthropic, OpenAI, OpenAI Responses, 사용자 지정 URL, 프록시, GLM 템플릿 동작은 유지하며 정책의 기본값은 꺼짐입니다.

**2026-10-15** 네이티브 보강 후보는 진행 중인 요청을 중단하지 않는 다음 슬롯 우선 배정, 실제 네이티브 원본 프로필을 따르는 스키마 기반 승인 판정과 90초/ask 기본값, 72% 압축과 64K까지의 16/32KiB 도구 출력 제한을 추가합니다. 선택형 strict 정책은 루프백과 명시적 추론 CIDR만 허용하도록 좁혀 LAN/Docker 전환 안내를 제공하며, 리디렉션·프록시와 모든 Agent 검색·업데이트 네트워크 동작을 차단하되 로컬 상태·롤백은 유지합니다. 읽기 전용 GPU 메모리 추정치·다른 모델 경고, 승인 설정 로드 안전성, 영어·한국어·중국어 간체 화면 문구를 함께 제공합니다. 호스트 전체 오프라인이나 모델 품질 보장이 아니며 의존성·마이그레이션·자동 모델 다운로드·릴리스는 추가하지 않습니다. [제공자 안내](llm-providers.md)와 [후보 검증](VERIFICATION.md#네이티브-보강-후보--2026-10-15)을 참고하세요.

**2026-10-03**에는 서버 번역의 최종 점검을 완료하고 GLM-5.3 설정 템플릿과 추론을 항상 켜야 하는 모델의 호환 처리를 추가했습니다. 템플릿은 기존 제공자 연결 방식을 사용하며 프로필을 자동으로 만들거나 활성화하지 않습니다.

ARTEX의 후속 커밋 `e2c8a23`, `86729b6`, `a951e4a`를 백포트했습니다.
프로덕션 SSE의 동일 출처 연결, 승인 모델의 별도 토큰 집계, 데이터베이스 오류 시
인증 거부, 최초 암호의 원자적 생성, 데이터베이스 연결 풀 제한을 포함합니다.
새 메시지와 배포 안내는 영어와 한국어로 제공됩니다. 백포트 커밋에 원저자를
명시했으며 기존 ScopeWeaver 변경 사항은 유지합니다.

## Norma 실행·문맥 압축 수정 — 2026-10-25

저장소가 관리하는 `third_party/norma` 대체 모듈의 원본은
[`52f17dd52d95b087265e5d5b306fe85c1ea05599`](https://github.com/Autumn-27/Norma/commit/52f17dd52d95b087265e5d5b306fe85c1ea05599)입니다.
이 커밋은 v0.4.3(`320ae32989da97dd91469bb89164cbfe87d83d5d`)에 Apache-2.0
라이선스만 추가합니다. 로컬 수정 전 파일은 211개, 1,293,448바이트이며,
해당 원본에는 별도의 NOTICE 파일이 없습니다.

로컬 수정은 실행기의 원래 시간 제한 컨텍스트를 정리 단계까지 유지하고,
재시도 테스트의 누락된 클라이언트를 보완하며, 작은 문맥 창의 기본 압축
간격을 조정하고, 요약이 충분히 쌓였는데도 다음 압축 단계가 실행되지 않는
문제를 해결합니다. 명확히 보고된 더 작은 문맥 한도만 학습하고, 학습한 상한을
다시 높이지 않으며, 출력 길이 오류와 문맥 초과를 구분합니다. 원본 대화와
보관 자료는 유지하고, 더 줄일 수 없는 문맥은 계속 명시적으로 실패합니다.
이미 사실이 아닌 작은 창의 한계 테스트는 실제 압축 동작을 확인하도록 바꿉니다.

`third_party/norma/README.scopeweaver.md`에 수정한 원본 파일 10개와 추가 파일
4개를 열거합니다. 수정한 원본 파일마다 변경 고지를 넣었습니다. 나머지 원본
파일, 원본 라이선스, 모듈 메타데이터는 변경하지 않았습니다. 공개 함수의
시그니처와 직렬화 형식은 유지하며, 위에 설명한 동작 수정은 의도된 변경입니다.

루트 모듈의 대체 설정과 Docker의 의존성 복사 순서가 이 소스를 선택합니다.
기존 압축 파일·컨테이너 패키징에 포함되는 `THIRD_PARTY_NOTICES.txt`에도
Apache 라이선스 전문을 넣었습니다. 루트 패키지 순회에는 중첩 SDK가 포함되지
않으므로 기존 backend CI 작업에서 SDK 전체 테스트를 별도로 실행합니다.
업스트림 저장소 게시나 데이터베이스 마이그레이션은 포함하지 않습니다.

호스트의 `enableNoa` 수정은 250K·1M을 포함한 기존 문맥 창 설정을 전달합니다.
설정값이 SDK의 200K 기본값으로 바뀌지 않도록 합니다. 출력 토큰 제한, Noa
비활성화, 네이티브 Ollama 정책은 별개로 유지합니다. [검증 안내](VERIFICATION.md)를
함께 확인하세요.
