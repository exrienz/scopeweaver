ScopeWeaver의 정적 GitHub Pages 소개 페이지입니다. 영어가 기본이며
(`landing/index.html`), 한국어·간체 중국어·번체 중국어·일본어·스페인어를 동등하게 제공합니다
(`landing/{ko,zh-Hans,zh-Hant,ja,es}/index.html`). 일반 HTML/CSS/JS를 사용하며
프레임워크, CDN, 추적기, 백엔드가 없습니다. 프로젝트 기본 경로 `/scopeweaver/`와
각 언어의 하위 디렉터리에서 상대 자산 경로로 제공합니다.

## 모드

설득. 이 화면은 제품의 진열창입니다. 개발자나 보안 연구자는 ScopeWeaver가 무엇인지,
어떻게 실행되는지, 작업이 어떻게 흐르고 코딩 에이전트가 어떻게 제어하는지 이해해야 합니다.
제품의 한계를 신뢰할 수 있어야 하며 릴리스나 설치 명령에 도달해야 합니다.

## 시각적 방향

애플리케이션 콘솔을 페이지 규모로 확장합니다.

- **바탕** `#fafafa`, **표면** `#ffffff`, 들어간 면 `#f4f4f3`.
- **잉크** `#171717`은 로고 타일과 화면 너비의 에이전트 구역에도 사용합니다.
  보조·삼차 텍스트에는 `#3f3f3f` / `#595959`를 사용합니다. 어두운 구역의 본문은
  `#fafafa`, 보조 텍스트는 `#adb0b8`입니다(색조가 있는 중립색, `#171717`에서 ≥ 6:1).
- **절제된 파란색 하나**를 링크·강조·포커스에만 사용합니다. 밝은 바탕에서는 `#2563eb`,
  hover는 `#1b45c9`; 어두운 구역에서는 `#7cafff` / `#a8c8ff`입니다. 링크 색은
  `--link` / `--link-hover`를 따르며 어두운 구역은 이 변수를 바꿔 hover도 읽히게 합니다.
- **가는 선** — 1px의 `#e6e6e4` / `#d4d4d2` 선으로 각 구역을 나누며 굵은 구분선은 쓰지 않습니다.
- **범위 격자 모티프** — 로고의 3×3 격자를 반영한 희미한 이축 격자를 히어로 뒤
  (방사형 마스크)와 에이전트 구역에 둡니다. 브리프에서 확정한 브랜드 모티프입니다.
  검사기는 장식 격자를 기본적으로 지적하지만 여기서는 확정한 시각적 방향이 우선합니다.
- **깊이** — 실제 오프셋과 부드러운 흐림이 있는 절제된 그림자를 사용하며 오프셋 없는
  색상 후광은 쓰지 않습니다. 스크린샷은 밝은 앱 창 프레임 안에 놓습니다.

## 타이포그래피

- **Schibsted Grotesk**(자체 호스팅 가변 woff2, 굵기 400–900, OFL)를 모든 표현에
  사용합니다. 제목 굵기는 640–660, 자간은 −0.028em이며 균형 있게 줄을 나눕니다.
  표시 제목은 약 3.7rem까지 늘어납니다.
- **JetBrains Mono**(자체 호스팅 가변 woff2, OFL)는 식별자, 명령, 출처, 칩에 사용하며
  `tnum`/`zero` 기능을 사용합니다.
- 라틴 글꼴만 자체 호스팅합니다. 한국어판은 라틴 표시 글꼴 뒤에 시스템 한글 글꼴
  (`Apple SD Gothic Neo`, `Pretendard`, `Malgun Gothic`, `Noto Sans KR`)을 둬
  ASCII의 인상을 두 언어에서 유지합니다. 한국어는 `word-break: keep-all`과
  `overflow-wrap: break-word`로 줄을 나눕니다. 본문의 인라인 `<code>` 식별자는
  `overflow-wrap: anywhere`를 써 긴 테스트 이름이 격자를 넓히지 않고 줄바꿈되게 합니다
  (쌓인 격자는 `minmax(0, 1fr)` 사용).
- 본문 행 길이는 약 33–68ch이며 기능 텍스트는 ≥ 11px입니다.

## 구조

가는 선으로 구분한 단일 열이며 구역별 밀도를 의도적으로 달리합니다.

1. **히어로** — 5/7 분할. 왼쪽에는 제안 문구와 동작, 오른쪽에는 실제 대시보드의 큰
   프레임 스크린샷을 둡니다.
2. **둘러보기** — 7/5 분할. 세로 ARIA tablist의 실제 화면 다섯 개
   (대시보드, 작업, 발견 사항, 시스템 설정, LLM 템플릿)가 고정된 프레임 스크린샷을
   바꾸고 화면별 한 줄 설명을 펼칩니다. 두 개의 연결된 그래프, 계획자 → 단일 의도
   작업자 → 사실/발견 사항, 사람의 검토, 재검증은 문장으로 설명하며 생성된 도식은 없습니다.
3. **에이전트 연동** — 화면 너비의 잉크색 구역입니다. 가로 ARIA tablist에서
   Claude Code / Codex / Pi 설치 명령을 전환하며 각각 복사 버튼이 있습니다.
   어댑터 도구 여덟 개와 정직한 "대체재가 아닌 제어 인터페이스" 설명을
   프레임으로 감싼 모바일 스크린샷 옆에 배치합니다.
4. **설치** — 복사 가능한 명령을 갖춘 구체적 경로 세 개(원클릭 스크립트,
   Docker Compose, 릴리스 압축 파일)와 플랫폼 압축 파일 칩 다섯 개, GHCR입니다.
5. **준비물** — PostgreSQL, 별도로 설정한 모델 제공자, 어댑터용 Node.js 22+,
   로컬 실습 대상을 네 개의 가는 선 셀로 보여 줍니다.
6. **한계와 출처** — 로컬 격리 환경 전용, 커밋 `75a706d`에서 수정된 과거 범위 개요 불일치(현재 상태는 [검증 문서](VERIFICATION.md) 참조; 전체 테스트 통과를 뜻하지 않음),
   운영·효과 보장 없음, Docker/Windows 미검증, npm audit 지적, 로컬 픽스처를 쓰는
   어댑터 테스트, 실제 코딩 에이전트에서 제공자까지의 실행은 독립적으로 검증하지
   않았다는 한계 목록을 VERIFICATION에 연결합니다. 옆에는 비식별 소유자 워크플로
   기록과 ARTEX/AGPL-3.0 출처, 글꼴·스크린샷 출처를 배치합니다.
7. **푸터** — 브랜드, 참고 링크, 라이선스, 실제 서비스가 아닌 소개라는 안내입니다.

## 대표 상호작용

둘러보기 tablist입니다. 화면 선택 시 프레임 스크린샷이 opacity로 교차 전환되며,
`grid-template-rows` 접기 애니메이션으로 설명을 펼칩니다. 구역마다 등장 효과를
반복하지 않고 이 한 곳에만 연출합니다. 세로 탭은 Up/Down/Home/End로 이동하는
roving tabindex를 쓰며 가로 에이전트 탭은 Left/Right를 사용합니다.

## 접근성과 상태

- 건너뛰기 링크, 랜드마크 영역, 이름이 있는 탐색, 눈에 보이는 테마별 포커스 테두리
  (밝은 바탕의 파란색, 어두운 바탕의 밝은 파란색)을 제공합니다.
- ARIA 탭에 올바른 `aria-selected` / `tabindex` / `hidden`을 설정하고 키보드로
  조작할 수 있게 합니다. 복사 버튼은 현지화된 상태(`Copy`/`Copied` · `복사`/`복사됨`)를
  알리며 클립보드 지원이 없으면 직접 선택하도록 안내합니다.
- 모바일 메뉴는 `aria-expanded`로 펼침을 표시합니다. 헤더 항목은 줄어들지 않으며
  ≤420px에서 간격을 좁혀 320px까지 대응합니다. 아이콘만 있는 GitHub 링크도
  접근 가능한 이름으로 시각적으로 숨긴 "GitHub" 텍스트를 유지합니다.
- 선택 영역, 스크롤바, 포커스 테두리, 링크 밑줄 간격, 표형 고정폭 숫자에 테마를 적용합니다.
- `prefers-reduced-motion`은 전환과 부드러운 스크롤을 해제합니다.
- 이미지에는 width/height와 `aspect-ratio`를 지정해 배치 이동을 막습니다. 히어로
  화면은 `fetchpriority="high"`, 나머지 아래쪽 화면은 지연 로드합니다.

## 정직한 설명과 출처

모든 스크린샷에 가상 데모 데이터라는 캡션을 답니다. 소유자 워크플로 문단은
비식별 조율 근거일 뿐이며 대상, 발견 사항, 메시지, 모델 사용량, 자격 증명을
포함하지 않습니다. 주장의 근거는 README, 어댑터 README, PROVENANCE,
VERIFICATION과 v0.1.0 변경 기록입니다. ScopeWeaver는 AGPL-3.0을 따르는
ARTEX 파생물이며 사용은 로컬로 격리한 연구로 제한됩니다.

## 수행한 검증(빌드 시점, 브라우저 외)

- `tools/validate-landing.mjs`(`landing/` 밖): 자산 존재, 상대 기본 경로 안전성,
  EN/KO id/tab/control 일치, 언어 교차 링크, 데모 캡션, 기획 메타데이터 미포함,
  `.nojekyll` 존재 — 17/17.
- JS와 검증 스크립트에 `node --check` 실행.
- Impeccable 검사기: 지적 19개 → 잔여 4개(어두운 구역과 정적으로 짝지은 단일
  강조 hover, 안쪽 래퍼로 들여 쓴 확정된 전체 너비 구역). 둘 다 올바르게 표시됩니다.
  권고로 남은 격자 모티프는 확정한 브랜드 방향입니다.
- 조정자가 Chrome에서 영어·한국어를 1440px와 390px로 확인하고 한 차례 수정한 뒤,
  두 언어 모두 320px에서도 가로 넘침이 없음을 확인했습니다. 스크린샷 탭,
  에이전트 탭, 키보드 전환, 모바일 메뉴, 언어 링크, 현지화 복사 피드백이 통과했습니다.
  브라우저 콘솔 오류는 없었습니다. 아래쪽 지연 스크린샷은 이동 시 로드되었습니다.
- Pages는 `landing/`만 배포합니다. 워크플로는 업로드 전에 파일 무결성과
  JavaScript 구문을 검사합니다. 개발 문서와 비공개 실행 데이터는 공개 산출물에 포함하지 않습니다.

## 구현 작업 표시

Claude Code를 `claude-opus-5-5`, medium effort로 요청했습니다. 주 구현 세션은
제공자 보호 장치의 중단 뒤 자동으로 `claude-opus-4-8`로 전환되었습니다.
범위를 제한한 브라우저 QA 수정 세션은 전부 `claude-opus-5-5`, medium effort로
실행했습니다. 따라서 이 페이지의 구현을 Opus 5.5만의 작업으로 표시하지 않습니다.
