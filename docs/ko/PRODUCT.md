## 플랫폼
web

## 기술 구성
애플리케이션은 Go 백엔드, 내장 Next.js 프런트엔드, PostgreSQL을 사용합니다. 별도로 승인된 GitHub Pages 소개 페이지는 일반 HTML, CSS, JavaScript를 사용하며 애플리케이션 백엔드 없이 실행되어야 합니다.

## 사용자
로컬로 격리한 연구·검증 환경에서 AI 보조 워크플로를 평가하는 개발자와 보안 연구자입니다. 이 대상 사용자와 여섯 언어의 애플리케이션·문서 범위는 소유자가 승인했습니다.

## 제품 목적
목표 계획, 에이전트, 자산 범위, 커버리지, 기록된 발견 사항, 사람의 검토를 하나의 자체 호스팅 연구 콘솔에서 조율합니다. 소개 페이지는 방문자가 제품을 이해하고, 과장 없는 증거를 확인하며, 다운로드·설치 문서에 도달하도록 돕습니다.

## 포지셔닝
공유 자산 그래프와 작업별 탐색 그래프가 대상을 에이전트의 탐색 방향, 관찰, 증거와 연결합니다. 외부 에이전트 제어 어댑터는 Claude Code, Codex, Pi에 작업·발견 사항 워크플로를 제공합니다.

## 운영 환경
PostgreSQL과 별도로 설정한 모델 제공자가 있어야 에이전트를 실행할 수 있는 자체 호스팅 애플리케이션입니다. GitHub Pages는 공개된 정적 소개를 호스팅하며, 실제 보안 테스트 서비스나 백엔드가 아닙니다.

## 기능과 제약
기능과 설치 방법의 근거는 README.md, adapters/agent/README.md와 코드입니다. 릴리스 v0.1.0은 플랫폼별 압축 파일 다섯 개와 다중 아키텍처 Docker 이미지를 제공합니다. 어댑터는 제어 인터페이스이며 내부 에이전트를 대체하거나 코딩 구독을 API 키로 전환하지 않습니다. 저장소의 사용 제한은 로컬로 격리한 연구·검증을 허용하고 온라인 대상 테스트를 금지합니다. 과거에 상속된 백엔드 범위 개요의 불일치는 커밋 `75a706d`에서 수정했습니다. 검증 근거와 제한은 [VERIFICATION.md](VERIFICATION.md)를 참조하세요. 이 수정만으로 현재 전체 테스트 통과나 운영 준비 완료를 주장할 수는 없습니다.

## 브랜드 원칙
ScopeWeaver 이름과 기존 범위 격자 로고를 유지합니다. 애플리케이션 스크린샷은 절제된 파란색 강조를 쓰는 정밀하고 중립적인 콘솔의 인상을 기준으로 삼습니다. 기본 언어는 영어이며 한국어, 간체 중국어, 번체 중국어, 일본어, 스페인어를 선택할 수 있습니다. ARTEX의 저작자 표시와 AGPL-3.0을 존중합니다.

## 확보한 근거
저장소의 screenshots/en과 screenshots/ko 스크린샷에는 가상 데모 데이터가 표시되므로 데모 스크린샷이라고 명시해야 합니다. 기존 로고는 web/public/scopeweaver.svg입니다. README, 출처, 검증 메모, 어댑터 문서, 릴리스 산출물이 일차 근거입니다. 로그인된 로컬 UI에서 소유자가 실제로 실행한 대화 하나를 확인했습니다. 이 대화에는 작업 생성, 탐색 그래프와 작업자 추적 확인, 한국어 진행 보고가 기록되어 있습니다. 공개 페이지는 개인정보를 보호하는 워크플로 요약만 사용할 수 있으며, 대상 이름, 원문 메시지, 취약점 주장, 토큰 수, 비공개 스크린샷은 사용할 수 없습니다. 이는 조율 기능의 근거이며 독립적인 보안 검증이 아닙니다. 검증된 고객 추천, 도입 통계, 성능 벤치마크, 외부 감사를 거친 보안 주장은 제공되지 않았습니다.

## 제품 원칙
제품 주장은 확인할 수 있어야 합니다. 공개 소개, 데모 픽스처, 실제 실행을 구분합니다. 진입 경로 가까이에 설치·모델 요구 사항을 배치합니다. 범위·승인 장치를 보존합니다. 자격 증명, 대상 세부 정보, 비공개 대화를 절대 공개하지 않습니다.

## 접근성과 포용성
데스크톱·모바일 반응형 웹, 키보드로 조작 가능한 컨트롤, 읽기 쉬운 대비, 움직임 줄이기 지원, 완전한 영어·한국어·간체 중국어·번체 중국어·일본어·스페인어 문구를 제공합니다.
