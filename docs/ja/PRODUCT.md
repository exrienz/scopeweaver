<a id="scopeweaver-product"></a>
# ScopeWeaver の製品定義



<!-- impeccable:product-schema 1 -->

<a id="platform"></a>
## プラットフォーム
web

<a id="stack"></a>
## 技術構成
アプリケーションは Go バックエンド、埋め込み Next.js フロントエンド、PostgreSQL を使います。承認済みの独立した GitHub Pages ランディングページは、通常の HTML、CSS、JavaScript を使い、アプリケーションのバックエンドなしで動作する必要があります。

<a id="users"></a>
## 利用者
ローカルの隔離環境での研究・検証に、AI 支援の作業フローを評価する開発者とセキュリティ研究者。この対象読者と、6 言語のアプリケーション・ドキュメントの範囲は所有者が承認済みです。

<a id="product-purpose"></a>
## 製品の目的
目標の計画、エージェント、資産のスコープ、カバレッジ、記録した検出事項、人間のレビューを、1 つのセルフホスト型の研究コンソールで連携させます。ランディングページは、製品の理解、率直な証拠の確認、ダウンロード・初期設定ドキュメントへの案内を担います。

<a id="positioning"></a>
## 位置付け
共有の資産グラフとタスク別の探索グラフが、対象をエージェントの方向、観測、証拠に紐付けます。外部エージェント操作用アダプターは、タスクと検出事項の作業フローを Claude Code、Codex、Pi に公開します。

<a id="operating-context"></a>
## 動作環境
セルフホストのアプリケーションで、PostgreSQL と、エージェントの実行用に別途設定したモデルプロバイダーが必要です。GitHub Pages は公開の静的な紹介ページを提供し、実際のセキュリティテストサービスやバックエンドではありません。

<a id="capabilities-and-constraints"></a>
## 機能と制約
機能と初期設定は README.md、adapters/agent/README.md、コードに基づきます。リリース v0.1.0 は、5 つのプラットフォーム用アーカイブとマルチアーキテクチャの Docker イメージを提供します。アダプターは操作用のインターフェースであり、内部エージェントの代わりや、コーディングのサブスクリプションを API キーに変換するものではありません。リポジトリの使用制限は、ローカルの隔離環境での研究・検証を認め、オンラインの対象のテストを禁止します。過去のスコープ概要テストの不一致はコミット `75a706d` で修正されています。現在の検証と制限は検証資料を参照し、テスト全体の成功や本番運用の準備完了を一括して主張しないでください。

<a id="brand-commitments"></a>
## ブランド上の方針
ScopeWeaver の名前と既存のスコープグリッドのロゴを保持します。アプリケーションのスクリーンショットが示す、控えめな青のアクセントによる、精密で中立的なコンソールの印象に従います。英語を既定とし、韓国語、簡体字中国語、繁体字中国語、日本語、スペイン語を選択できます。ARTEX の作者と AGPL-3.0 を尊重します。

<a id="evidence-on-hand"></a>
## 保有する証拠
リポジトリの screenshots/en と screenshots/ko のスクリーンショットは架空のデモデータを表示しており、デモ画面と明記する必要があります。既存のロゴ: web/public/scopeweaver.svg。README、出典、検証記録、アダプターのドキュメント、リリース成果物が一次資料です。所有者が実際に実行した会話を、ログイン済みのローカル UI で確認しました。タスク作成、探索グラフとワーカートレースの確認、韓国語の進捗更新が記録されています。公開ページで使えるのは、このプライバシーに配慮した作業フローの要約のみです。対象名、生のメッセージ、脆弱性の主張、トークン数、非公開のスクリーンショットは使えません。これは作業の連携の証拠で、独立したセキュリティ検証ではありません。検証済みの顧客の推薦、利用統計、性能ベンチマーク、外部監査済みの安全性の主張は提供されていません。

<a id="product-principles"></a>
## 製品の原則
製品の主張を確認可能に保ちます。公開の紹介、デモのテストデータ、実際の実行を区別します。初期設定とモデルの要件を入口の近くに示します。スコープと承認の仕組みを保持します。認証情報、対象の詳細、非公開の会話は決して公開しません。

<a id="accessibility--inclusion"></a>
## アクセシビリティと利用しやすさ
デスクトップ・モバイルに適応するウェブ画面、キーボードで操作できるコントロール、読みやすいコントラスト、動きの軽減への対応、英語・韓国語・簡体字中国語・繁体字中国語・日本語・スペイン語の完全な文言を用意します。
