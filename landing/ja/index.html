セルフホスト型コンソールで 複数エージェントによるセキュリティ探索をを利用します。

ScopeWeaver は、目標の計画、自律エージェント、資産のスコープ、カバレッジ、記録した検出事項を、1 つの審査画面で連携させます。自分のマシン上で、ローカルの隔離した実験対象に使う設計です。

v0.1.0 をダウンロード 初期設定ガイド

Go バックエンド · 埋め込み Next.js · PostgreSQL。 元のプロジェクト: ARTEX。ライセンスは AGPL-3.0。

実際の画面で、1 つのタスクの流れを見る

ScopeWeaver は、 対象が何か と どこまでテストしたか を、共有の資産グラフとタスク別の探索グラフという、連携する 2 つのグラフに分けます。画面を選び、各段階の場所を確認してください。

コーディングエージェントから操作

ローカルのアダプターにより、Claude Code、Codex、Pi から、ScopeWeaver 自身の認証付き API を通じて、タスクを作成し、進捗、カバレッジ、検出事項を取得できます。

操作用のインターフェースです。内部の仕組みはそのまま使います。 内部のプランナー、ワーカー、モデル設定を維持し、コーディングエージェントのサブスクリプションをモデル API キーへ変換しません。読み取りは既定で有効で、タスク作成と一時停止・再開は、次の設定で明示的に有効にします: SCOPEWEAVER_ALLOW_WRITES=trueを利用します。

claude mcp add --transport stdio scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
codex mcp add scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
pi -e /absolute/path/scopeweaver/adapters/agent/pi-extension.js
  • health バックエンドと LLM の準備状態
  • list_tasks 状態、件数、ページ送り
  • get_task タスク 1 件の保存済み状態
  • get_coverage タスクの資産カバレッジ
  • list_findings 絞り込みとページ送り付きの検出事項
  • get_finding 詳細、証拠、レポート
  • create_task タスクを作成・スケジュール（書き込み）
  • control_task 一時停止・再開（書き込み）

Node.js 22 以上、実行中のバックエンド、既存の管理者ログインが必要です。ツールが返す証拠は信頼できない対象側の内容で、指示ではありません。認証情報は環境変数に保持し、エラーでは伏せます。

ローカルにインストールして実行

ScopeWeaver は自分のマシンでセルフホストします。方法を選び、 http://localhost:8787 を開いてください。初回は /setup で管理者パスワードを設定します。

推奨

ワンクリックスクリプト

リポジトリをクローンしてインストーラーを実行します。Docker を検出し、Docker 内での実行かローカルビルドを選べます。

git clone https://github.com/cskwork/scopeweaver.git cd scopeweaver ./install.sh
docker

Docker Compose

Postgres パスワードを次に設定します: .env。Compose がソースからイメージをビルドし、Postgres と一緒に起動します。

cp .env.example .env docker compose up -d --build
ビルド済み

リリースアーカイブ

対応プラットフォームのアーカイブを取得し、DB の接続を設定して、監視スクリプトから起動します。

cp config.example.json config.json ./start.sh
linux amd64 linux arm64 macos amd64 macos arm64 windows amd64 GHCR の Docker イメージ

すべてのアーカイブに、埋め込みウェブ画面、監視スクリプト、スキル、設定例、エージェントアダプターを同梱します。 v0.1.0 リリースと SHA256SUMS を確認 →

最初に必要なもの

ScopeWeaver はアプリケーションを提供します。データベースとモデルプロバイダーは利用者が用意します。

PostgreSQL

接続可能な Postgres データベース。スキーマを埋め込み、起動ごとに冪等に作成します。

モデルプロバイダー

別途設定した LLM が必要です。次を設定するか: ANTHROPIC_API_KEY または OPENAI_API_KEY、UI から入力してください。未設定では探索を実行できません。

Node.js 22 以上（アダプター）

コーディングエージェント用アダプターにのみ必要です。依存関係を次でインストールします: npm ci 実行する場所: adapters/agentを利用します。

ローカルの実験対象

自分が所有するシステムを隔離環境で使用してください。ScopeWeaver はオンラインのテストではなく、ローカルの隔離された研究用です。

率直な制限

このリリースの範囲と限界を、リポジトリで確認できる形で示します。

  • ローカルの隔離環境での研究のみ。 上流からの使用制限は、許可の有無を問わず、オンラインサービスへのスキャン、検査、攻撃を禁止します。自分のシステムを隔離して使用してください。
  • 本番運用や有効性は主張しません。 本番のペネトレーションテストへの準備や、独立して検証したセキュリティ成果を主張するものではありません。
  • 未検証の実行環境。 Docker イメージと Windows バッチの実行は未検証です。パッケージのテスト用ケースは、実際の Windows 実行を実証しません。
  • 依存関係の対応が必要。 対象を絞ったツール更新で、監査指摘のすべてを解消したとは限りません。現在の監査コマンドと残る制限は検証記録を参照してください。
  • アダプターはローカルのテスト用実装で検証。 ローカルの要求・応答の契約を証明するだけで、実際のコーディングエージェントとプロバイダー間の実行は独立検証していません。参照: 検証の詳細を利用します。
