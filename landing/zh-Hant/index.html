自行代管的控制台，協調多代理程式安全探索.

ScopeWeaver 在同一審查介面中協調目標規劃、自主代理程式、資產範圍、覆蓋率與已記錄的發現；在您自己的電腦上執行，僅適用於本機隔離的實驗室目標。

下載 v0.1.0 設定指南

Go 後端 · 內嵌 Next.js · PostgreSQL。衍生自 ARTEX，依 AGPL-3.0 授權。

透過實際畫面走完一項任務

ScopeWeaver 將目標是什麼與已測試到哪裡分為兩張相連的圖：共用資產圖及各任務的探索圖。選取畫面，即可查看各階段的位置。

透過程式開發代理程式操作

本機配接器讓 Claude Code、Codex 與 Pi 透過 ScopeWeaver 自身的已驗證 API，建立任務並讀取進度、覆蓋率與發現。

這是控制介面，並不取代內部代理程式。配接器保留 ScopeWeaver 內部規劃器、工作代理程式與模型設定，也不會將程式開發代理程式訂閱轉換為模型 API 金鑰。預設允許讀取；建立任務與暫停／繼續需選擇性啟用 SCOPEWEAVER_ALLOW_WRITES=true.

claude mcp add --transport stdio scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
codex mcp add scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
pi -e /absolute/path/scopeweaver/adapters/agent/pi-extension.js
  • health 後端與 LLM 就緒狀態
  • list_tasks 狀態、計數、分頁
  • get_task 單一任務的持久狀態
  • get_coverage 任務資產覆蓋率
  • list_findings 篩選與分頁後的發現
  • get_finding 詳情、證據與報告
  • create_task 排程任務（寫入）
  • control_task 暫停／繼續（寫入）

需要 Node.js 22+、執行中的後端與既有管理員登入。工具傳回的證據為不受信任的目標內容，絕不能視為指示。憑證保留在您的環境中，錯誤訊息會遮蔽憑證。

安裝並在本機執行

ScopeWeaver 由您自行代管，在您的電腦上執行。選擇安裝方式，然後開啟 http://localhost:8787；首次造訪會進入 /setup 以設定管理員密碼。

建議

一鍵指令碼

複製儲存庫並執行安裝程式；它會偵測 Docker，提供全 Docker 或本機建置選項。

git clone https://github.com/cskwork/scopeweaver.git cd scopeweaver ./install.sh
Docker

Docker Compose

在 .env 設定 Postgres 密碼；Compose 會從原始碼建置映像檔，並同時啟動 Postgres。

cp .env.example .env docker compose up -d --build
預先建置

發行封存檔

下載平台封存檔，填寫資料庫連線設定，再透過監督指令碼啟動。

cp config.example.json config.json ./start.sh

事前需求

ScopeWeaver 提供應用程式；資料庫與模型供應商由您準備。

PostgreSQL

可連線的 Postgres 資料庫。結構已內嵌，每次啟動都會冪等建立。

模型供應商

另行設定的 LLM：設定 ANTHROPIC_API_KEY 或 OPENAI_API_KEY，或在介面輸入。未設定模型時無法執行探索。

Node.js 22+（配接器）

僅程式開發代理程式配接器需要。請執行 npm ci，工作目錄為 adapters/agent。

本機實驗室目標

僅能用於您擁有且隔離執行的系統。ScopeWeaver 適用於本機隔離研究，禁止線上測試。

如實說明限制

以下說明本版本的能力與限制，均可對照儲存庫查證。

  • 僅限本機隔離研究。繼承的使用限制禁止掃描、探測或攻擊任何線上服務，無論是否獲得授權。僅得用於您擁有且已隔離的系統。
  • 不宣稱可供正式環境使用或具備已驗證的成效。本專案不宣稱已具備正式環境滲透測試就緒程度，也不宣稱安全結果經獨立驗證。
  • 未驗證的執行環境。尚未驗證 Docker 映像檔與 Windows 批次檔的實際執行。封裝測試資料不代表真實 Windows 執行環境測試。
  • 相依套件仍需改善。針對工具的更新未解決所有稽核問題。目前稽核指令與剩餘限制請見驗證說明。
  • 配接器測試使用本機測試資料。測試僅證明本機請求／回應契約；尚未獨立驗證程式開發代理程式至供應商的實際執行。詳見 驗證詳情.
