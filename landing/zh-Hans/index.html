自行托管的控制台，协调多智能体安全探索.

ScopeWeaver 在同一审查界面中协调目标规划、自主智能体、资产范围、覆盖率与已记录的发现；在您自己的电脑上运行，仅适用于本地隔离的实验室目标。

下载 v0.1.0 配置指南

Go 后端 · 内嵌 Next.js · PostgreSQL。衍生自 ARTEX，依 AGPL-3.0 授权。

通过实际画面走完一项任务

ScopeWeaver 将目标是什么与已测试到哪里分为两张相连的图：共用资产图及各任务的探索图。选取画面，即可查看各阶段的位置。

通过编程智能体操作

本地适配器让 Claude Code、Codex 与 Pi 通过 ScopeWeaver 自身的已验证 API，创建任务并读取进度、覆盖率与发现。

这是控制界面，并不取代内部智能体。适配器保留 ScopeWeaver 内部的规划器、工作智能体和模型配置，也不会将编程智能体订阅转换为模型 API 密钥。默认允许读取；如需创建任务和暂停／继续任务，请显式启用 SCOPEWEAVER_ALLOW_WRITES=true。

claude mcp add --transport stdio scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
codex mcp add scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
pi -e /absolute/path/scopeweaver/adapters/agent/pi-extension.js
  • health 后端和 LLM 的就绪状态
  • list_tasks 状态、数量和分页
  • get_task 单个任务的持久化状态
  • get_coverage 任务资产覆盖率
  • list_findings 筛选并分页后的发现
  • get_finding 详情、证据和报告
  • create_task 调度任务（写入操作）
  • control_task 暂停／继续（写入操作）

需要 Node.js 22+、运行中的后端与既有管理员登录。工具传回的证据为不受信任的目标内容，绝不能视为指示。凭证保留在您的环境中，错误消息会遮蔽凭证。

安装并在本地运行

ScopeWeaver 由您自行托管，在您的电脑上运行。选择安装方式后，打开 http://localhost:8787；首次访问会进入 /setup，以设置管理员密码。

建议

一键脚本

复制仓库并运行安装程序；它会侦测 Docker，提供全 Docker 或本地构建选项。

git clone https://github.com/cskwork/scopeweaver.git cd scopeweaver ./install.sh
Docker

Docker Compose

在 .env 中设置 Postgres 密码；Compose 会从源代码构建镜像，并同时启动 Postgres。

cp .env.example .env docker compose up -d --build
预先构建

发行封存档

下载平台封存档，填写数据库连接配置，再通过监督脚本启动。

cp config.example.json config.json ./start.sh

事前需求

ScopeWeaver 提供应用程序；数据库与模型供应商由您准备。

PostgreSQL

可连接的 Postgres 数据库。结构已内嵌，每次启动都会幂等创建。

模型供应商

单独配置的 LLM：设置 ANTHROPIC_API_KEY 或 OPENAI_API_KEY，也可以在界面中输入。未配置模型时无法运行探索。

Node.js 22+（适配器）

仅编程智能体适配器需要。安装依赖时，请运行 npm ci，工作目录为 adapters/agent。

本地实验室目标

仅能用于您拥有且隔离运行的系统。ScopeWeaver 适用于本地隔离研究，禁止线上测试。

如实说明限制

以下说明本版本的能力与限制，均可对照仓库查证。

  • 仅限本地隔离研究。继承的使用限制禁止扫描、探测或攻击任何线上服务，无论是否获得授权。仅得用于您拥有且已隔离的系统。
  • 不宣称可供正式环境使用或具备已验证的成效。本专案不宣称已具备正式环境渗透测试就绪程度，也不宣称安全结果经独立验证。
  • 未验证的运行环境。尚未验证 Docker 镜像与 Windows 批次档的实际运行。封装测试数据不代表真实 Windows 运行环境测试。
  • 依赖包仍需改善。针对工具的更新未解决所有审计问题。目前审计命令与剩余限制请见验证说明。
  • 适配器测试使用本地测试数据。测试仅证明本地请求／响应契约；尚未独立验证编程智能体至供应商的实际运行。详见 验证详情.
