Una consola autoalojada para exploración de seguridad multiagente.

ScopeWeaver coordina planificación de objetivos, agentes autónomos, alcance de activos, cobertura y hallazgos en una interfaz de revisión, diseñada para ejecutarse en tu equipo contra objetivos de laboratorio aislados localmente.

Sigue una tarea por las pantallas reales

ScopeWeaver divide qué es el objetivo y hasta dónde se ha probado en dos grafos vinculados: uno compartido de activos y otro de exploración por tarea. Selecciona una pantalla para ver cada etapa.

Contrólalo desde tu agente de programación

Un adaptador local permite a Claude Code, Codex y Pi crear tareas y leer progreso, cobertura y hallazgos mediante la API autenticada de ScopeWeaver.

Es una interfaz de control, no un sustituto. Conserva planificador, trabajadores y configuración internos y no convierte una suscripción de agente en clave API de modelo. Las lecturas están activadas por defecto; crear y pausar/reanudar se habilitan con SCOPEWEAVER_ALLOW_WRITES=true.

claude mcp add --transport stdio scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
codex mcp add scopeweaver \ -- node /absolute/path/scopeweaver/adapters/agent/src/mcp.js
pi -e /absolute/path/scopeweaver/adapters/agent/pi-extension.js
  • health Disponibilidad de backend y LLM
  • list_tasks Estado, recuentos, paginación
  • get_task Estado persistente de una tarea
  • get_coverage Cobertura de activos de tarea
  • list_findings Hallazgos filtrados y paginados
  • get_finding Detalles, pruebas e informe
  • create_task Programar tarea (escritura)
  • control_task Pausar / reanudar (escritura)

Requiere Node.js 22+, backend activo y acceso administrativo existente. Las pruebas devueltas son contenido objetivo no confiable, nunca instrucciones. Las credenciales permanecen en el entorno y se ocultan de los errores.

Instalar y ejecutar localmente

ScopeWeaver es autoalojado y funciona en tu equipo. Elige una ruta y abre http://localhost:8787 ; la primera visita lleva a /setup para establecer la contraseña de administrador.

Script con un clic

Clona el repositorio y ejecuta el instalador; detecta Docker y ofrece instalación completa en Docker o compilación local.

git clone https://github.com/cskwork/scopeweaver.git cd scopeweaver ./install.sh

cp .env.example .env docker compose up -d --build

Qué necesitas primero

ScopeWeaver aporta la aplicación; tú proporcionas la base de datos y un modelo.

PostgreSQL

Una BD Postgres accesible. El esquema se integra y crea idempotentemente en cada inicio.

Proveedor de modelos

Un LLM configurado aparte: establece ANTHROPIC_API_KEY o OPENAI_API_KEY, o introdúcelo en la interfaz. La exploración no funciona sin uno.

Node.js 22+ (adaptador)

Solo para el adaptador de agentes. Instala dependencias con npm ci en adapters/agent.

Un objetivo local de laboratorio

Úsalo solo contra sistemas propios o ejecutados en aislamiento. ScopeWeaver es para investigación aislada local, no pruebas en línea.

Límites claros

Qué es esta versión y qué no. Se puede comprobar en el repositorio.

  • Solo investigación aislada local. Las restricciones heredadas prohíben escanear, sondear o atacar servicios en línea, con o sin autorización. Úsalo en sistemas propios aislados.
  • Sin afirmaciones de producción ni eficacia. No afirma preparación para pruebas de penetración en producción ni resultados de seguridad validados independientemente.
  • Entornos sin verificar. No se verificaron ejecución de imagen Docker ni archivos por lotes Windows. Los casos de empaquetado no son pruebas reales de ejecución Windows.
  • Las dependencias requieren trabajo. Las actualizaciones específicas no resuelven todos los hallazgos de auditoría. Consulta la verificación para el comando actual y las limitaciones.
  • El adaptador se prueba con casos locales. Solo prueban el contrato local de solicitud/respuesta; la ejecución real desde agente a proveedor no está verificada independientemente. Consulta detalles de verificación.
Flujo del propietario · Anonimizado

Orquestación observada

Observado en el espacio del propietario: crear tareas desde chat, inspeccionar trazas y actualizar progreso en coreano. Se omiten datos identificativos y hallazgos de seguridad.

Procedencia y créditos

ScopeWeaver es una obra derivada independiente de ARTEX en el commit original 160fe13, con licencia AGPL-3.0. Las capacidades de agentes usan el SDK norma ; la sincronización de activos se basa en ScopeSentry.

Las capturas muestran datos ficticios incluidos, etiquetados como demostración, no escaneos reales. Las fuentes son Schibsted Grotesk y JetBrains Mono autoalojadas (SIL Open Font License). El coreano usa la fuente Hangul del sistema del lector.
