# OpenCode SDK ブリッジ

[English](README.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md) · [日本語](README.ja.md) · [Español](README.es.md)

任意で使用するループバック専用ブリッジです。固定した **OpenCode ネイティブ CLI／クライアント／SDK 2.1.4** と、別途テストした **旧 SDK／CLI 1.19.4** の組み合わせに対応します。対話、ツール実行、承認、スコープ検査、再試行、圧縮は ScopeWeaver が管理します。ブリッジはモデルの 1 ステップをストリーム配信してツール要求を収集し、ScopeWeaver のツールや OpenCode の組み込みツールを実行しません。従来の API／OpenCode Go プロバイダーはブリッジなしで利用できます。

## 起動

テスト済み CI ランタイムは **Bun 1.3.14** です。新しいバージョンは未検証です。

```sh
cd adapters/opencode-sdk
bun install --frozen-lockfile --ignore-scripts
export SCOPEWEAVER_OPENCODE_TOKEN="$(openssl rand -hex 32)"
bun run start
```

ブリッジトークンは**空白以外の 32 文字以上**が必要です。非公開のネイティブ CLI サーバーは呼び出しごとに生成する独立したパスワード（`OPENCODE_PASSWORD`）と HTTP Basic 認証を使います。ブリッジトークンや上流プロバイダーキーとは別です。

ScopeWeaver のプロバイダープロファイルで `opencode-sdk`、URL `http://127.0.0.1:4097` を選び、上記の**ブリッジトークン**を入力します。クラウド API キーとは別です。OpenCode Go／Console のトークンを流用しないでください。モデル一覧を読み込んで正確な `providerID/modelID` を選びます。

既定の未ログインランタイムは、独立したカタログと公開モデル探索を使用します。探索は公開カタログへの GET のみで、**推論を実行しません**。公開一覧に現在存在し、固定ランタイムが認識する料金ゼロの OpenCode モデルだけを表示します。カタログ取得失敗はエラーです。掲載は利用資格、残り割当量、推論成功の証明ではありません。無料モデルは変更・削除される場合があり、既定では有料モデルや認証情報へのフォールバックを行いません。

**2026-10-25（KST）の過去の検証：** 製品のネイティブ CLI／クライアント 2.1.4 ブリッジを通じ、`opencode/deepseek-v4.1-flash-free` で実際の ScopeWeaver 対話が完了しました。実推論 3 回で UI 接続テスト、ファイルに影響する前に確認・承認したホストツール要求、最終画面の回答 `FREE_OK` を確認しました。既定の料金ゼロのカタログを使用し、API キー、アカウントの取り込み、モデル／応答のモック、識別情報の偽装、有料モデルへの切替は使用していません。ネイティブツールは阻止され、ホスト操作は ScopeWeaver が実行しました。これは当日の既存の証拠であり、今回の再実行結果ではありません。

ネイティブ推論は固定された本物の CLI と公式クライアント API を使用し、推論なしの探索には埋め込み SDK を使います。以前の収集専用の埋め込み SDK 経路は HTTP 403 `FreeTierError` で拒否されました。旧版でのホステッド無料アクセスは未検証です。モデルや利用資格は変わるため、当日のテストは数値的な割当量や継続提供を保証しません。構造化された拒否は `free_tier_restricted` として返し、有料モデルを選びません。

`SCOPEWEAVER_OPENCODE_PORT` で既定の 4097 を変更できます。`SCOPEWEAVER_OPENCODE_HOST` は `127.0.0.1` に固定します。ブラウザーの `Origin` 付き要求と非ループバック URL は拒否します。すべての API 経路にトークンが必要です。パスワード同様に保護してください。

`SCOPEWEAVER_OPENCODE_TIMEOUT_MS` は呼び出し全体の期限 **0–86,400,000 ミリ秒**です。既定 **0** はホストのキャンセルに委ね、隠れた 2 分の推論期限はありません。キャンセル／終了には別途 **1.5 秒**の強制終了期限があります。公開カタログ取得は **10 秒**です。要求本文は **16 MiB**、ツール引数 JSON 1 件は **2,000,000 文字**、ネイティブモデルのテキスト／思考／引数合計は **8,000,000 文字**、ワーカー出力は **20,000,000 バイト**が上限です。超過時は明示的に失敗し、データを切り詰めません。

## 専用プロバイダー設定

明示的な OpenAI 互換モデルやローカルテストモデルには、運用者が管理する JSON ファイルを `SCOPEWEAVER_OPENCODE_PROVIDER_CONFIG` に指定します。チェックアウト外、または Git が無視する `provider-config.local.json` という名前で保存します。

```json
{
  "providers": {
    "local": {
      "name": "Local model",
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "http://127.0.0.1:8000/v1",
        "apiKey": "explicit-provider-key-if-needed"
      },
      "models": {
        "my-model": {
          "name": "My model",
          "capabilities": { "tools": true },
          "limit": { "context": 200000, "output": 32000 },
          "compatibility": { "maxTokensField": "max_tokens" }
        }
      }
    }
  }
}
```

`local/my-model` を選択します。このファイルはブリッジの既定探索を置き換えます。ユーザー／プロジェクトの OpenCode 設定、`.env`、プラグイン、MCP サーバー、保存済み認証情報を読み込みません。明示した `apiKey` のみを対象プロバイダーに渡します。リモート推論は有料の場合があり、設定を追加しても無料にはなりません。任意の SDK パッケージや余分な設定キーは拒否します。

## 実行境界

呼び出しごとに独立した Bun ワーカーを使い、環境変数を許可リストに限定し、一時 home／設定／データを所有します。ネイティブモードは非公開の公式 CLI サーバー、実際の CLI `run`、一時 DB、1 回限りの認証付きループバック出口転送を所有します。公式クライアントが探索、セッションイベント、中断を処理します。クラウド認証情報、ユーザー認証ファイル、プロキシ、プリロード設定を継承しません。固定されたオプション依存のプラットフォームバイナリを直接使うため、`--ignore-scripts` が有効でグローバルインストールは不要です。**オプション依存を省略しないでください**。

OpenCode 本来の組み込みツール定義と実装を保持します。ネイティブ権限はすべて ASK で、CLI `--auto` は使いません。公開 `execute.before` ポリシーフックが、生成された `execute` を含むすべての非ホストツールを実行前に独立して拒否します。ネイティブツール要求はブリッジ要求を失敗させ、ScopeWeaver に渡しません。登録されたホスト収集関数だけが待機し、ホストツール要求になります。他のエージェントは削除します。衝突しない `sw_tool_N` 別名で既定ツールの上書きを防ぎ、説明には正確な元の名前・説明を残し、応答では元のホスト名を復元します。

ホストの system 部分を 2 改行で結合し、公開カスタムエージェント system 設定にそのまま渡します。OpenCode が生成するモデル／環境／ツールの文脈も保持します。最後のポリシー部分は `Host tool:` と記された関数だけが有効だと伝えます。公開 context フックでホストの役割、ツール ID／結果、呼び出しごとの制限・設定を保持します。system 配列がホスト部分のみになる保証はありません。モデル別の thinking／effort フィールドを転送し、未対応設定は明示的に失敗します。モデルの出力上限が要求より小さい場合はその上限に抑えます。入力、出力、キャッシュ使用量を分けて扱います。

2 回目のモデル要求は阻止します。非公開出口は本物の CLI が生成した要求を元の上流 URL に転送し、リダイレクトを拒否します。宛先、モデル、識別情報、認証情報を差し替えません。ホストツール要求は中断、セッション削除、所有プロセスの後片付け後にのみ返します。切断、DELETE、タイムアウト、終了で POSIX ワーカープロセスグループを停止し、**1.5 秒**後に強制終了します。このプロセスツリーの後片付けは Windows に未実装のため、**ネイティブと旧版の両方で Windows の推論を拒否**します。

CLI の公開設定ではシステム／MDM 設定探索を完全に無効化できません。macOS の `/Library/Application Support/opencode`、ユーザー／全体の `/Library/Managed Preferences` 下の `ai.opencode.managed.plist`、Linux の `/etc/opencode` が存在すると、ネイティブモードは `configuration_error` で起動を拒否します。アクセス不能な場所や壊れたシンボリックリンクも拒否し、その設定を読み取り・変更しません。

ネイティブモードは完了／ストリーム応答とホスト履歴の再生で、64 ビット整数を含むツール引数の生 JSON を保持します。JavaScript で解析した値は実行しません。正本となる生引数以外の危険な数値、未対応コンテンツ、不明なネイティブツール、重複ツール ID、不正な応答は拒否します。スキーマはインライン定義、ローカル JSON Pointer `$ref`／`$defs`、ユニオンに対応し、リモート参照、`$id`、`$dynamicRef`、未解決参照を拒否します。初期化では本来のプロバイダー／カタログコードを読み込みます。これはアプリケーションの境界であり、**OS サンドボックスではありません**。ループバックの先にクラウドモデルがあり得るため、ScopeWeaver のローカル専用推論条件を満たしません。

## バージョンと旧版の制限

| `SCOPEWEAVER_OPENCODE_RUNTIME` | 固定した組み合わせ | 機能応答 `runtime` |
| --- | --- | --- |
| `native`（既定） | 公式 CLI、`@opencode/client`、SDK **2.1.4** | `native` |
| `legacy` | `@opencode-ai/sdk/v2`、CLI **1.19.4** | `legacy` |

起動前に `SCOPEWEAVER_OPENCODE_RUNTIME=legacy` を指定すると旧 API を選べます。過去に実際のランタイムをローカル検証した範囲は **macOS arm64** です。Linux CI に実ランタイムテストを設定していますが、ホステッド実行結果は未確認です。他の SDK バージョンは推論前に拒否します。任意のバージョン／プラットフォームの互換性は保証しません。

旧版は対応する公式オプションバイナリを直接使用するため、`--ignore-scripts` が有効です。未初期化のラッパーやグローバル `opencode` は使いません。オプション依存を省略しないでください。所有する CLI とループバック MCP 収集サーバーは、要求ワーカーの POSIX プロセスグループと共に終了します。Windows ではこの境界を実装していません。呼び出しごとに専用のプラグインパッケージとロックのコピーを使い、共有依存への書き込み可能なリンクを作りません。

旧版は構造的に正しく安全に表現できる JSON／履歴のみ対応します。空白や同値の HTML／Unicode エスケープは正規化されるため、元の字句・バイトを保証しません。絶対値が **9,007,199,254,740,991** を超える危険な整数、不透明／署名付き思考履歴、未対応のプロバイダー上書きは明示的に失敗します。生の 64 ビット引数が必要ならネイティブを使います。旧版のカスタムプロバイダーは上の明示的 OpenAI 互換設定を使いますが、`max_tokens` 互換フィールド、対応ツール機能、コンテキスト／出力上限のみをマッピングします。未対応の `reasoningField` と機能上書きは拒否します。SDK の境界外の入力には既存 API／Go プロファイルを使えます。

## プロトコルと検証

プロトコルは **`scopeweaver-opencode-sdk`、バージョン 1**。認証経路は `GET /v1/capabilities`、`GET /v1/models`、`POST /v1/complete`、`POST /v1/stream`、`DELETE /v1/requests/{request_id}` です。ストリームは NDJSON で、実際のネイティブテキスト／思考差分、収集したツール要求、最終使用量を送り、成功時は `message_stop` を 1 回だけ返します。エラーは限定した機械コードと機密を除いたメッセージを使用します。明示的で構造化された請求／割当量枯渇だけを `quota_exhausted`（完了要求 HTTP 402）とし、一般のレート制限、認証、5xx を枯渇へ置き換えません。構造化されたコンテキスト超過は `context_length_exceeded`（HTTP 400）としてホストの圧縮信号を維持します。一般の 400 やメッセージ内の語句だけでは分類しません。構造化された `FreeTierError` は `free_tier_restricted`（HTTP 403）で、枯渇や通常の禁止とは分けます。ブリッジは代替モデルを選ばず、ホストの設定済みポリシーが次の処理を決めます。

完了要求例（ストリーム経路も同じ本文を受け付けます）：

```json
{
  "request_id": "unique-call-uuid",
  "session_id": "stable-host-conversation-uuid",
  "model": "local/my-model",
  "system": ["Host system instructions"],
  "messages": [{ "role": "user", "content": [{ "type": "text", "text": "Hello" }] }],
  "tools": [],
  "max_tokens": 64,
  "thinking": "disabled"
}
```

任意フィールドは `session_id`、`temperature`、文字列配列 `stop`、`thinking`、`thinking_type`、`reasoning_effort`。ホストコンテンツは `text`、assistant の `thinking`／`tool_use`、テキスト結果を持つ user の `tool_result` に対応します。ツール定義は `name`、`description`、`input_schema` を使います。完了応答は `message`、`stop_reason`（`end_turn`、`tool_use`、`max_tokens`）と入力／出力／キャッシュ読み取り／書き込みを分けた `usage` を含みます。公開契約と制限は [protocol.mjs](src/protocol.mjs)、転送は [bridge.mjs](src/bridge.mjs) を参照してください。

`opencode-go` では `session_id` により、呼び出しごとの新 SDK セッションでも `x-opencode-session` を一定にします。未指定なら `request_id` を使います。`opencode` は実ランタイム生成のセッション／識別ヘッダーを維持します。通常のプロバイダーにゲートウェイ専用ヘッダーは付けません。本物の CLI の User-Agent を保持します。

```sh
bun run check
bun test --timeout 30000
```

固定した実際の CLI／クライアント／SDK とローカル SSE モデルで、推論なし探索、ホスト履歴／設定、収集の安全性、ストリーム／使用量、生の数値引数、悪意あるネイティブ要求、同時実行の隔離、キャンセルを検証します。ホステッド無料モデルの実際の利用資格は証明しません。

## ScopeWeaver プロファイルとダウングレード境界

空のトークンで保存済み値を保持できるのは同じ SDK エンドポイントだけです。宛先や形式を変えた際に古いトークンを流用しません。`localhost`、`127.0.0.1`、`::1` は別の認証スコープです。SDK テンプレートは未保存のクラウドキー、プロキシ、独自セッションヘッダーを消し、モデルを空にします。探索・推論・保存・有効化は行いません。**モデル読み込み**を明示的に実行し、**接続テスト**はクリック時だけ推論します。

プロファイル DB の `CHECK` 制約に `opencode-sdk` を追加します。SDK プロファイルが残ると古いバイナリは起動できません。ダウングレード前に DB をバックアップし、現在のバージョンで旧対応形式へ変換するか SDK プロファイルを削除します。過去の移行検証は使い捨て DB のみで、稼働中の DB は移行していません。[プロバイダーガイド](../../docs/ja/llm-providers.md#opencode-sdk-bridge)を参照してください。
